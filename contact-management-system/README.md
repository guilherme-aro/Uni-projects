# Contact Management System

A simple and efficient command-line contact management system built in Python.

## 📋 Description

This project allows users to:
- Register new contacts with name, phone, and email
- List all saved contacts in alphabetical order
- Search for specific contacts by name
- Edit contact information (phone or email)
- Delete one or more contacts
- Persist data to a local file (contatos.txt)

## 🚀 Features

✅ Simple and intuitive interface
✅ Input validation
✅ Alphabetical sorting
✅ Multiple contact deletion
✅ Data persistence
✅ Error handling

## 📦 Requirements

Python 3.6+

## 💻 How to Run

```bash
python main.py
```

- File handling
