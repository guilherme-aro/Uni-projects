# Hotel Registration System

A simple hotel reservation system that calculates accommodation costs.

## 📋 Description

This program simulates a hotel reservation system where guests register and the system calculates the total cost based on apartment type, number of people, and length of stay.

## 🚀 Features

✅ Input validation for all fields
✅ Two types of apartments with different pricing
✅ Capacity up to 6 people per apartment
✅ Maximum 7 days per reservation
✅ Automatic cost calculation
✅ Clear reservation summary

## 📦 Requirements

Python 3.6+

## 💻 How to Run

```bash
python hotel_registration.py
```

## 💰 Pricing

Apartment Type 1: R$ 20-54 per day
Apartment Type 2: R$ 25-63 per day

## ✨ Validation Rules

- Name: Only letters and spaces
- Apartment type: 1 or 2
- People: 1-6
- Days: 1-7
