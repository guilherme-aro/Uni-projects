# Guess the Number Game

A fun and simple number guessing game built in Python.

## 📋 Description

Try to guess a random number between 1 and 100. The game tells you if your guess is too high or too low.

## 🚀 Features

✅ Simple and fun gameplay
✅ Input validation
✅ Counts the number of tries
✅ Clear feedback (higher/lower)
✅ Menu system

## 📦 Requirements

Python 3.6+

## 💻 How to Run

```bash
python game.py
```

## 🎮 How to Play

1. Run the game
2. Choose option "1" to play
3. Enter your guess (1-100)
4. The game will tell you if the number is higher or lower
5. Keep guessing until you get it right!

## 🎓 Learning Objectives

- Random number generation
- Input validation
- Loops and conditionals
- Try/except exception handling
- Menu system design
