# Uni-Projects 🎓

A collection of Python projects developed during my Computer Science degree (ADS - Análise e Desenvolvimento de Sistemas).

## 📚 Overview

This repository contains various projects built to learn and practice Python programming concepts. Each project is organized in its own directory with complete documentation and code.

## 🚀 Projects

### 1. 📞 [Contact Management System](./contact-management-system/)
A command-line application for managing contact information.
- Register, list, search, edit, and delete contacts
- Input validation and error handling
- Data persistence with file storage
- Status: ✅ Complete

### 2. 🎮 [Guess the Number Game](./game-guess-the-number/)
An interactive number guessing game between 1 and 100.
- Random number generation
- Player feedback (higher/lower)
- Try counter
- Status: ✅ Complete

### 3. 🏨 [Hotel Registration System](./hotel-registration/)
A hotel reservation system that calculates accommodation costs.
- Guest registration with validation
- Automatic cost calculation
- Reservation summary
- Status: ✅ Complete
