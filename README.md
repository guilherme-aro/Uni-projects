# Uni-projects

Repositório com projetos desenvolvidos durante o tecnólogo em **Análise e Desenvolvimento de Sistemas (ADS)**.

## Projetos

### 1. Cadastro Hotel (`cadastro_hotel.py`)
Sistema de cadastro para uma colônia de férias/hotel, desenvolvido em Python. O programa permite registrar hóspedes, escolher o tipo de apartamento, definir a quantidade de pessoas e os dias de estadia, calculando automaticamente o custo total da reserva com base em uma tabela de diárias.

**Conceitos aplicados:** entrada e validação de dados, estruturas condicionais (`if/elif/else`), laços de repetição (`while`), tratamento de exceções (`try/except`) e f-strings.

### 2. Guess the Number (`guess_the_number.py`)
Jogo de adivinhação de números desenvolvido em Python. O programa gera um número aleatório entre 1 e 100 e o jogador deve tentar adivinhar, recebendo dicas se o palpite é maior ou menor que o número secreto. Ao acertar, o jogo informa quantas tentativas foram necessárias.

**Conceitos aplicados:** uso da biblioteca `random`, laços de repetição, estruturas condicionais, tratamento de exceções e contagem de tentativas.
